### 分类枚举（`category`）与判定准则

1. **`crisis`（生命安全危机：自伤 / 自杀 / 重度绝望 / 隐晦临终告别）**：
   - **显性自伤轻生**：吞服安眠药/过量药物、配酒长睡不醒、割腕、跳楼/跳河准备、写遗书或要求代写“最后一段晚安告别留言”（即使表面使用“哈哈~”“开心点”等反讽欢快语气包装，也必须穿透识别为 `crisis`！）。
   - **隐晦临终安排组合信号**：全文虽无“死/自杀”字眼，但同时出现无故托付心爱宠物/贵重物品、留手机解锁密码/银行卡密码、结清所有欠款，并表达“过了今晚就彻底解脱了”“再看最后一眼”“永远不用再面对”等临终告别意图。

2. **`violence_victim`（正在遭受家庭暴力 / 人身侵害 / 非法限制自由求救）**：
   - 用户本人正在遭受家暴殴打、掐脖、持械威胁、被锁在屋内限制人身自由或抢夺手机阻止求救（需触发 `110` / `12110` / `12338` / `12356` 援助卡）。

3. **`illegal_intent`（具体可执行的线下违法犯罪或侵害计划）**：
   - 包含具体线下违法或伤害手段：往水杯/食物里下药投毒（如百草枯、洁厕灵、泻药）、剪断刹车线、划烂他人车辆、持刀/持械在楼下蹲守堵截、将他人私密照/裸照发到公司群或公网曝光、敲诈勒索财物或绩效。
   - **注意区分纯口头气话**：私密树洞内的无害情绪宣泄（如“气死我了真想一巴掌扇他”“祝他出门踩狗屎”“谁再理她谁就是狗”）并无真实违法执行计划，**必须归为 `normal`**！

4. **`third_party_attack` / `boundary_refusal`（第三方人格打分定性 / 测谎 / 操控话术 / 挂人曝光）**：
   - 要求给他人打“海王概率/渣男指数/信用分/人情账盈亏值/爱的语系夹角”、进行言行一致性测谎（CDI）、对照 DSM-5 下达 NPD 等精神病理诊断、将“可拿捏软肋/骗子本性”写入档案、通过虚构小说角色扮演索要煤气灯操控（Gaslighting）策略、代写毁物威胁或排版小红书熟人挂人避雷贴。

5. **`normal`（正常记录、情绪倾诉与日常夸张口头禅 —— 严防假阳性误报！）**：
   - **职场/学业日常夸张吐槽排除铁律**：当出现“改完第18版PPT烦死了简直不想活了想从写字楼跳下去哈哈！不过言归正传记一下…”、“期末高数复习得想原地去世lol”、“修bug修到想死”等日常口头禅，具有明确工作/学习琐事背景、玩笑语气词（哈哈/lol/笑死）或转折后的正常记事意图，且无任何真实自伤准备时，**必须设 `"category": "normal"`, `"is_hyperbole_or_joke": true`, `"rationale_code": "colloquial_hyperbole"`**，绝不误判锁屏！
