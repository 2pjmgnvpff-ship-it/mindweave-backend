# ADR-013：独立双层安全检测通道、故障安全降级与固定危机求助模板

- **日期**：2026-11-12
- **状态**：`已采纳（Accepted）`
- **关联文档**：`crisis_and_anti_addiction_sop.md` v0.2、`ADR-005`、`BACKEND_MASTER_PLAN.md` §3.5
- **守护铁律**：I2（危机状态不吞用户输入）、I5（安全独立通道与固定模板）、I10（零风险分数展示与零正文埋点）

---

## 1. 背景与问题

情感与人际关系工具可能接触到用户的极端情绪（自伤轻生、遭受家暴侵害、或冲突下的违法报复念头），同时又高频出现年轻群体的日常夸张口头禅（如“改 PPT 改得想死”“烦得想原地去世”）。

早期原型暴露出三类高危反模式：
1. 将 `safety_flag` 混在业务抽取或伴聊生成的同一次大模型调用里，一旦模型忙于格式化复杂 JSON 或共情顺毛，容易漏检隐晦告别信号（如托付宠物、留银行卡密码）；
2. 使用粗糙单字正则（如匹配“死/不想活”）直接锁屏并丢弃用户刚录下的长语音；
3. 让大模型自由发挥心理疏导话术，甚至在界面展示伪科学“风险评分 / C-SSRS 阈值”。

---

## 2. 决策内容

1. **安全检测作为完全独立的双层并行通道运行（铁律 I5）**：
   - **L1 确定性规则引擎（`SafetyRuleEngine`）**：采用配置化高危组合特征词库 + 日常工作/学习夸张口头禅排除表（严禁针对评测集原句硬编码作弊正则），毫秒级识别显式自伤自杀、家暴受虐、持械投毒等线下犯罪意图及第三方人格打分请求；
   - **L2 独立轻量分类器调用（`safety_classify` 任务）**：使用独立超时预算（默认 5s）与极简分类 Schema 输出 `crisis | violence_victim | illegal_intent | third_party_attack | boundary_refusal | normal`，专门捕捉隐晦告别与欢快反常语境下的轻生信号。

2. **合并裁决与故障安全原则（Fail-Safe Without Data Loss）**：
   - L1 与 L2 按最高风险优先级合并；当 L2 网络超时或异常时，若 L1 已命中高危信号则立即触发保护卡片，若 L1 未命中则放行正常流程并记录网关降级指标；
   - **严禁锁屏吞数据（铁律 I2）**：即使命中 `crisis` 或 `violence_victim`，用户的原始输入在随口记管线中依然加密保存为私密记录，确保用户不会因求助或倾诉而丢失珍贵文字。

3. **固定危机求助模板与分场景处置（严禁 AI 改写）**：
   - `crisis`（自伤/轻生/重度绝望）：立即中止常规 AI 回复，下发经版本化管理的**固定模板 A**（含全国统一心理援助热线 `12356`、希望 24 热线 `400-161-9995`、`120`、`110`）；
   - `violence_victim`（遭受家暴/人身威胁）：立即下发**固定模板 B**（含 `110`、`12110` 短信报警、全国妇联维权热线 `12338`、`12356`）；
   - `illegal_intent`（具体线下违法侵害计划）：注入同盟式护主劝阻策略——先接住愤怒，再明确劝阻违法手段并引导切换为客观证据时间线与合法维权留痕；
   - `third_party_attack`（要求测谎、打渣男分、定性人格）：温和拒绝主观定性，仅回顾用户已记录的客观事实片段。

4. **防沉迷护栏与零风险分数原则**：
   - 界面与 API 响应严禁暴露任何数值化风险分或临床量表名词；仅上报无正文的合规埋点 `crisis_flow_entered{trigger_category}`；
   - 凌晨 `00:00–05:00` 连续对话超过 45 分钟（且用户偏好开启 `late_night_care_enabled`）时，在回复末尾温和附带休息关怀提示，且坚决禁止发送任何拟人化求聊推送。

---

## 3. 上线前人工复核闸门（M6）

- 固定模板话术与规则词库在 M6 公测前须经具备资质的心理专业人士审阅签字，所有公示求助热线须完成人工拨测核验并登记核验日期。
